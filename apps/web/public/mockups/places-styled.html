Places drill-down — current design beside the style guide

The same screens three ways: the design you approved this evening, then the same thing in the new style guide's light mode (Mint) and dark mode (Night · mint). Every phone is live: fold countries, open a city, use the dropdowns, switch to the map. Nothing in the app has changed.

What the guide changed, and two calls to check

Applied from the guide

  • Type. Archivo throughout: headings 800 with tight tracking, screen titles 28px, body 15px, labels 12px uppercase. Caveat only on the wordmark.
  • Light mode. White ground, one mint field for the header with Deep leaf sub-copy, ink buttons and ink selected chips, Leaf icons on transparent, soft mint rules, Mint tint for open panels. No mint buttons, no mint type on white.
  • Dark mode. Charcoal ground, raised cards and chips, icon wells, off-white type and icons, mint only for the primary button and the selected chip, the bottom bar a step darker.
  • Shape. 4px corners on buttons, cards, segments, menus and icon wells; chips stay pills; 1px rules; no shadows, no gradients. The map placeholder is flat Mint tint with rule lines.
  • No per-row colour coding. The green / purple / gold counts on the city rows become plain outlined counts. Map pins take the type colour: filled for been, hollow for to try.
  • Red is the heart. The guide reserves red for "the mark of a place you love", so Special is now a small red heart badge on the row's icon and on its pin — not a gold box or a star. The rating star is in the icon colour.

Two judgement calls

  • The Underground line dot keeps its real colour (Central, Piccadilly …). That is the line's own identity, not a UI code, so I read it as outside the "no colour coding" rule. If you'd rather, it becomes an ink dot with the line named in words.
  • Special = the red heart. This equates your "Special" with the guide's "favourite". If Special should stay distinct from a favourite, say so and it gets a different mark.
